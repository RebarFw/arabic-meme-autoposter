1. In the app's **Manage messaging & content on Instagram** use case, add/authorize `@avexiro0` as the Instagram professional account/tester if it is not already connected. Accept any Instagram tester invitation from that account. Authentication and permission prompts require the account holder.
2. Generate the Instagram **User** access token with `instagram_business_basic` and `instagram_business_manage_messages`. Save it in the ignored `.secrets/meta-access-token.txt`. Save the associated Instagram app secret in `.secrets/meta-app-secret.txt`. These files must contain just the credential; do not paste credentials into chat.
3. `npm run secrets:install` securely uploads the files. `npm run meta:diagnose` verifies profile and conversation access. `npm run setup` verifies Meta and Buffer refer to the same Instagram account and subscribes `messages` while leaving the app unpublished.
4. If configuring the webhook in Meta, use `https://arabic-meme-autoposter.meme-autoposter.workers.dev/webhooks/instagram`. Paste the verification token locally with `Get-Content -Raw .secrets/meta-verify-token | Set-Clipboard`. Do not display that value or put it in chat. Use the Worker `/privacy` URL for the privacy policy. Subscribe the Instagram `messages` field. An unpublished app may not deliver real webhooks; minute polling is the intended ingestion path.
